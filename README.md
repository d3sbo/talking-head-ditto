# talking-head-ditto

A small Flask server that turns a block of text into a lip-synced talking-head video. It generates speech with a TTS engine, animates a still avatar with [Ditto](https://github.com/antgroup/ditto-talkinghead) running on TensorRT, saves the MP4 and sends a Home Assistant notification when it's done.

I use it to produce a spoken daily summary video that Node-RED triggers each morning and a Home Assistant dashboard card plays back.

## How it works

1. `POST /generate` with the summary text
2. Speech is generated by one of two engines:
   - **XTTS v2** (separate TTS server, port 5051) with sentence-by-sentence generation
   - **Voicebox** (port 17493) using a cloned voice profile and auto-chunking
3. Ditto (TensorRT, Ampere+ engines) animates `avatar.jpg` to the audio
4. The video lands in `output/` and Home Assistant gets a notification with a link

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/health` | Health check used by Docker and Node-RED |
| POST | `/generate` | Generate a video from text (see `body.json` for an example payload) |
| GET | `/video/<filename>` | Serve a generated video |

## Requirements

- NVIDIA GPU, Ampere or newer (built and tested on an RTX 3080)
- Docker with the NVIDIA container runtime
- A reachable XTTS v2 and/or Voicebox server
- Home Assistant long-lived access token (for notifications)

## Setup

```bash
cp .env.example .env        # fill in your values
# add your own avatar image at server/avatar.jpg
docker compose up -d --build
```

The image build clones Ditto and downloads its checkpoints from Hugging Face, so the first build is large and slow.

`server/talking_head_server.py` is bind-mounted into the container, so edits only need a container restart, not a rebuild.
